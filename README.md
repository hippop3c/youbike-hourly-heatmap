# 雙北 YouBike 分時熱力圖

本網站呈現 2026 年 7 月 CPS 民眾滿借／空還紀錄、調度作業，以及 CPS Report「見車見位率」報表的各站分時資料。

- 平假日、城市、行政區與指標皆可複選並疊加比較。
- 友愛接力（滿借、空還）的圖形強度使用所選日別在該小時的交易筆數。
- 調度行為分為「調出＋綁車」與「調入＋解綁車」，各項數字使用該月同一時段所有任務中的最大車輛數；同時選平日與假日時取兩者較大值。
- 「見車率」與「見位率」是兩個可獨立勾選的百分比指標，來源為 CPS Report 的「見車見位率」報表。
- 調度圖標固定在友愛接力圖標下層，並以較大的外圈呈現，重疊時仍可辨識。
- 可逐時選擇 00–23 時，或播放 24 小時動態變化。

## 見車率／見位率計算

- 資料期間為 2026 年 7 月，剔除 7/10、7/11、7/12；有效天數為平日 22 天、假日 6 天。
- 每個站點、日別與小時的百分比，是 Report 報表中該組合之有效每日百分比的算術平均：`有效百分比合計 ÷ 有值天數`。
- 只選平日或假日時直接顯示該日別平均；同時選平日與假日時，依有效天數加權：`(平日平均 × 22 + 假日平均 × 6) ÷ 28`。
- 若其中一個日別缺值，加權分母只採用有值日別的天數；兩者都缺值時顯示「—」，且不繪製該率的站點標記。`0%` 是有效數值，會納入平均而不會當成缺值。
- 左下摘要的見車率／見位率，是目前城市、行政區篩選後「有資料站點」的算術平均，不是各站百分比相加。

## 既有指標的資料口徑

- 滿借／空還沿用原資料版本，剔除 7/10、7/11；這與見車率／見位率另排除 7/12 的口徑不同。
- 滿借／空還以平日 22 天、假日 7 天換算所選小時的交易筆數；同時選兩個日別時加總筆數。
- 調度沿用 7 月任務資料的同時段最大車輛數，不套用日數平均；同時選平日與假日時取兩者較大值。

## 更新 Report 資料

`rebuild_report_rates.py` 只使用 Python 標準函式庫，會驗證日期、欄位、數值範圍、重複列、場站代號與場站基本資料，再原子更新 `data.js`、`data-summary.json` 與場站比對報告。可用 `--report`（可重複）、`--station-basic`、`--period` 與 `--exclude` 指定下一批來源。

開啟 `index.html` 即可使用；若瀏覽器限制本機資料載入，請以本機 HTTP 伺服器開啟。
